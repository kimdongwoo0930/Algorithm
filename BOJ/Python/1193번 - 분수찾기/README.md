<p>이와 같이 나열된 분수들을 1/1 → 1/2 → 2/1 → 3/1 →&nbsp;2/2 → … 과 같은 지그재그 순서로 차례대로 1번, 2번, 3번, 4번, 5번, … 분수라고 하자.</p>

<p>X가 주어졌을 때, X번째 분수를 구하는 프로그램을 작성하시오.</p>



## 입력 형식


<p>첫째 줄에 X(1 ≤ X ≤ 10,000,000)가 주어진다.</p>



## 출력 형식


<p>첫째 줄에 분수를 출력한다.</p>
