# 로그인 성공?

> 🔗 https://school.programmers.co.kr/learn/courses/30/lessons/120883
> 📂 주제: 문자열 · Lv0

## 문제 설명

머쓱이는 프로그래머스 사이트의 로그인 기능을 구현하려 합니다.
아이디와 비밀번호를 입력받아

- 로그인에 성공하면 `"login"`
- 아이디는 존재하지만 비밀번호가 일치하지 않으면 `"wrong pw"`
- 아이디가 존재하지 않으면 `"fail"`

을 return 하는 solution 함수를 완성해주세요.

## 제한사항

- 회원들의 아이디는 알파벳 소문자와 숫자로만 이루어져 있습니다.
- 회원들의 비밀번호는 숫자로만 이루어져 있습니다.
- 회원들의 비밀번호는 **중복될 수 있지만 아이디는 중복되지 않습니다.**
- `id_pw`의 길이 = 2
  - `id_pw[0]`은 아이디, `id_pw[1]`은 비밀번호
  - 1 ≤ 아이디 길이 ≤ 15
  - 1 ≤ 비밀번호 길이 ≤ 6
- 1 ≤ `db`의 길이 ≤ 10
  - `db`의 원소는 `[아이디, 비밀번호]` 형태이고 길이는 2

## 입출력 예

| id_pw                      | db                                                                       | result       |
| -------------------------- | ------------------------------------------------------------------------ | ------------ |
| `["meosseugi", "1234"]`    | `[["rardss","123"], ["yyoom","1234"], ["meosseugi","1234"]]`              | `"login"`    |
| `["programmer01","15789"]` | `[["programmer02","111111"], ["programmer00","134"], ["programmer01","1145"]]` | `"wrong pw"` |
| `["rabbit04","98761"]`     | `[["jaja11","98761"], ["krong0313","29440"], ["rabbit00","111333"]]`      | `"fail"`     |

### 입출력 예 설명

**예 #1**
`db`에 아이디와 비밀번호가 모두 일치하는 회원이 있으므로 `"login"`입니다.

**예 #2**
아이디 `programmer01`은 존재하지만 비밀번호가 `1145`로 다르므로 `"wrong pw"`입니다.

**예 #3**
아이디 `rabbit04`가 `db`에 없으므로 `"fail"`입니다.
