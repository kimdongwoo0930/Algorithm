# 치킨 쿠폰

> 🔗 https://school.programmers.co.kr/learn/courses/30/lessons/120884
> 📂 주제: 반복문 · Lv0

## 문제 설명

프로그래머스 치킨은 치킨을 시켜먹으면 **한 마리당 쿠폰을 한 장** 발급합니다.
**쿠폰을 열 장 모으면 치킨을 한 마리 서비스로 받을 수 있고**,
서비스로 받은 치킨에 대해서도 쿠폰을 한 장 발급받을 수 있습니다.

시켜먹은 치킨의 수 `chicken`이 매개변수로 주어질 때
받을 수 있는 **최대 서비스 치킨의 수**를 return 하도록 solution 함수를 완성해주세요.

## 제한사항

- `chicken`은 정수입니다.
- 0 ≤ `chicken` ≤ 1,000,000
- 쿠폰이 10장 미만으로 남으면 더 이상 교환할 수 없습니다. (**남은 쿠폰은 다음 교환에 누적됩니다**)

## 입출력 예

| chicken | result |
| ------- | ------ |
| `100`   | `11`   |
| `1081`  | `120`  |

### 입출력 예 설명

**예 #1**
치킨을 100마리 주문했으므로 쿠폰이 100장 발급되어 서비스 치킨 10마리를 받습니다.
그 10마리로 쿠폰 10장이 다시 발급되어 서비스 치킨 1마리를 더 받습니다.
따라서 `10 + 1 = 11`입니다.

**예 #2**

| 단계 | 가진 쿠폰    | 받는 치킨 | 남는 쿠폰 | 누적 서비스 |
| ---- | ------------ | --------- | --------- | ----------- |
| 1    | 1081         | 108       | 1         | 108         |
| 2    | 108 + 1 = 109 | 10        | 9         | 118         |
| 3    | 10 + 9 = 19  | 1         | 9         | 119         |
| 4    | 1 + 9 = 10   | 1         | 0         | 120         |
| 5    | 1 + 0 = 1    | -         | -         | 종료        |

따라서 `108 + 10 + 1 + 1 = 120`입니다.
