> 프로그래머스는 `class Solution` 하나만 제출하므로 **단일 파일**로 관리합니다.

## 📝 네이밍 규칙

### 1. 코딩테스트 입문 — 문법 주제별

[입문 문제 목록](https://school.programmers.co.kr/learn/challenges/beginner?languages=java)은 챕터 구분 없이 Lv0 문제가 평평하게 나열되어 있어,
**복습할 때 문법으로 찾을 수 있도록** 아래 주제를 직접 정해 씁니다.

| 폴더명       | 여기에 넣는 문제                              |
| ------------ | --------------------------------------------- |
| `사칙연산`   | 정수 연산, 나머지, 몫, 형변환                 |
| `조건문`     | if / 삼항연산자 / switch                      |
| `반복문`     | for, while, 중첩 반복                         |
| `문자열`     | String 메서드, char 다루기, StringBuilder     |
| `배열`       | 1차원 배열, Arrays 유틸                       |
| `2차원 배열` | 행렬, 중첩 배열                               |
| `컬렉션`     | List, Map, Set                                |
| `수학`       | 약수/배수, 소수, 진법                         |
| `스트림`     | stream, map, filter로 줄여 쓴 풀이            |

- 문제 폴더는 **문제 이름 그대로** — 전부 Lv0이라 `Lv0.` 접두사는 붙이지 않습니다
- 예: `코딩테스트 입문/문자열/문자 반복 출력하기/`

### 2. 고득점 Kit — 알고리즘 유형별

프로그래머스 **고득점 Kit** 분류를 그대로 사용합니다.

| 폴더명       | 원본 분류        |
| ------------ | ---------------- |
| `해시`       | 해시             |
| `스택과 큐`  | 스택/큐          |
| `힙`         | 힙(Heap)         |
| `정렬`       | 정렬             |
| `완전탐색`   | 완전탐색         |
| `탐욕법`     | 탐욕법(Greedy)   |
| `동적계획법` | 동적계획법(DP)   |
| `DFS-BFS`    | 깊이/너비 우선   |
| `이분탐색`   | 이분탐색         |
| `그래프`     | 그래프           |

- 문제 폴더는 `Lv{레벨}. {문제 이름}` — 예: `Lv1. 완주하지 못한 선수`
- 유형이 섞여 있으면 **문제가 의도한 자료구조** 폴더에 넣습니다

> ⚠️ 폴더명에 `/`는 쓸 수 없으므로 `스택/큐` → `스택과 큐`, `DFS/BFS` → `DFS-BFS`로 씁니다.

### 3. 공통

- 문제 이름은 프로그래머스에 표시된 그대로 (띄어쓰기 포함)
- **문제 번호는 폴더명에 넣지 않고**, 문제 README 최상단에 링크로 기록

| 파일            | 역할                            |
| --------------- | ------------------------------- |
| `README.md`     | 문제 요약 + 배운 문법 / 풀이    |
| `Solution.java` | 제출한 최종 코드                |

- 클래스명은 프로그래머스 제출 형식 그대로 `Solution` → 파일명도 `Solution.java`
- 템플릿의 `main`은 **로컬 테스트용**이라 제출할 땐 빼면 됩니다

## ⚠️ 문제 폴더를 만들 때의 원칙

이 리포의 목적은 **문제를 해결하는 것이 아니라 Java 문법을 직접 손으로 익히는 것**입니다.
그래서 새 문제 폴더를 만들 때는 **문제 정보와 빈 스캐폴드까지만** 준비하고, 풀이는 직접 작성합니다.
(AI에게 폴더 생성을 부탁할 때도 이 범위를 지킵니다.)

| 미리 채워두는 것                                    | 비워두는 것                                      |
| --------------------------------------------------- | ------------------------------------------------ |
| README의 문제 설명 / 제한사항 / 입출력 예 / 예 설명 | `solution` 메서드 본문                           |
| `Solution.java`의 클래스·메서드 시그니처            | README의 "익힌 문법" / "더 깔끔하게" 섹션        |
| `main`의 예제 테스트 호출 (기대값은 주석으로)       | `Java/README.md` 문법 노트의 해당 문제 관련 내용 |

- 문법 노트는 **풀고 나서** 직접 채웁니다. 미리 적으면 그게 곧 정답입니다
- 풀이 목록에는 우선 `🚧 풀이 중`으로 올리고, 통과하면 익힌 문법을 적습니다

## 🚀 새 문제 추가하는 법

```bash
# 1. 템플릿 복사 (입문 / 고득점Kit 중 맞는 쪽)
cp -r "_template/입문" "Java/코딩테스트 입문/문자열/문자 반복 출력하기"

# 2. README에 문제 정보 옮겨 적기 (여기까지가 준비)
# 3. Solution.java 직접 작성

# 4. 로컬에서 바로 실행 (JDK 11+ 단일 파일 실행)
cd "Java/코딩테스트 입문/문자열/문자 반복 출력하기" && java Solution.java

# 5. 통과한 뒤에 새로 배운 문법을 Java/README.md 문법 노트로 옮기기
# 6. 아래 풀이 목록 갱신
```
