## 🗂️ 폴더 구조

```
Algorithm/
├── BOJ/            # 백준 온라인 저지
│   ├── Python/     # 풀이 + Python 모듈 학습 기록
│   └── Java/       # 풀이
├── Programmers/    # 프로그래머스
│   └── Java/
│       ├── 코딩테스트 입문/   # Lv0, 문법 주제별
│       └── 고득점Kit/         # Lv1+, 알고리즘 유형별
└── SQL/            # MySQL 기반 SQL 학습 및 쿼리 정리
```

---

## 🛠️ 개발 환경

- **BOJ**: [BOJ VS Code Extension](https://github.com/kimdongwoo0930/BOJ-Extenstion-for-VSCode) 활용하여 풀이
  - ※ HTML 파일은 Extension 사용으로 인해 자동 생성된 파일입니다.
- **Programmers**: Extension이 없어 [`_template`](./Programmers/_template)을 복사해 직접 정리
- **SQL**: VSCode + Docker + MySQL 환경에서 직접 실습
