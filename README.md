## 🛠️ 개발 환경

- **BOJ**: [BOJ VS Code Extension](https://github.com/kimdongwoo0930/BOJ-Extenstion-for-VSCode) 활용하여 풀이
  - ※ HTML 파일은 Extension 사용으로 인해 자동 생성된 파일입니다.
- **프로그래머스**: [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub) Extension으로 자동 커밋 — 레벨별 폴더에 문제 저장
- **SQL**: VSCode + Docker + MySQL 환경에서 직접 실습
